# Frotto 
Protótipo navegável em HTML, CSS e JavaScript puro (sem build, sem frameworks).

## Acesso (dados de demonstração)
Use qualquer senha com 8 ou mais caracteres e uma destas matrículas:

| Matrícula | Perfil           | Telas disponíveis                                              |
|-----------|------------------|----------------------------------------------------------------|
| ADM001    | Administrador    | Todas                                                          |
| GES001    | Gestor de Frota  | Início, Documentos, Enviar Documentos, Relatórios              |
| COL001    | Colaborador      | Início, Documentos                                             |
| GES002    | (inativo)        | Login bloqueado                                                |

## Observações
- Os dados ficam em memória: recarregar a página restaura o estado inicial.
